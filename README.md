## How it was made
- Made in godot
- Using trenchboom for level design
- func_godot for importing trenchboom maps into godot
- imgui plugin for godot for debug
## Why it was made
- wanted to mess around with portal plugins for godot
- that kinda got out of hand
- also wanted to mess around with new godot / trenchboom plugins and i found one that actually works
